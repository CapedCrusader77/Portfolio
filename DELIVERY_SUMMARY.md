```bash

# Visit http://localhost:5173
```

### Step 2: Personalize (10-30 minutes)
Edit `src/App.tsx`:
- Update `developerData`
- Update `skills` array
- Update `projects` array
- Update `experience` array
- Update `chatResponses`

### Step 3: Customize (Optional, 20-60 minutes)

